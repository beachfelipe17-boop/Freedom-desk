# The Freedom Desk

This is a simple phone-friendly static website.

## Easiest way to edit
Open `script.js` and edit the stories inside `const stories = [...]`.

Example:
{
  category: "Kentucky",
  title: "Your headline",
  text: "Your short story description."
}

Categories: Latest, Politics, Kentucky, Opinion.

## Publish for free
A simple option is GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository.
3. Upload all four files: index.html, style.css, script.js, logo.jpeg.
4. In the repository, open Settings → Pages.
5. Choose the main branch and root folder, then save.
6. GitHub will give you a free web address ending in `github.io`.

You can edit `script.js` from GitHub's website on your iPhone whenever you want to change stories.

A custom `.com` domain is optional and usually costs money.
